ACR Mod Manager 0.1.0 — first public release

- Standalone Windows installer; Stage Exporter is not required.
- Manual Scan, supported stage detection, fresh menu tables and backups.
- Enable/Disable, Restore backup, English and Spanish interface.
- Stage images and descriptions preserved.
- Unknown mods and detected table conflicts shown explicitly.
- Your records online!, mod submission contact and GitHub update notifications.

Download ACR-Mod-Manager-Setup.exe below. SHA256SUMS.txt verifies the installer.
Requires Windows x64, WebView2 and ACR build 26756580. First extraction requires Internet. Installer is unsigned.
No level packs or original game tables are included. External mods are not automatically supported. The 160-route catalogue is not a claim of individual in-game testing for all routes.
